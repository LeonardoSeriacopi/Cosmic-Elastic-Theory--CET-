# \### Kids\_Inspire/

# 

# 00\_reference\_data  

# Curated reference datasets from the INSPIRE survey, including relic classifications

# and structural-age indicators, directly taken from the literature.

# 

# 01\_data\_consolidation  

# Consolidation of INSPIRE and KiDS-derived quantities into unified,

# galaxy-level data products.

# 

# 02\_dispersion\_peak  

# Extraction of dispersion-peak observables for individual relic galaxies,

# using the same pipeline applied to random anchors.

# 

# 03\_consolidated\_tests  

# Summary-level tests exploring trends with redshift, structural age,

# and other global properties of the relic sample.

# 

# 04\_individual\_tests  

# Object-level diagnostic analyses for individual relic galaxies,

# including scripts and selected figures.

# These tests are illustrative and not used in the main statistical comparisons.

# Raw intermediate data products are intentionally omitted.

# 

# 05\_comparative\_analyses  

# Direct comparative tests between relic galaxies and random KiDS anchors,

# including regime-occupancy analyses and support-exclusion tests.

# This directory contains the primary results used in the paper.
