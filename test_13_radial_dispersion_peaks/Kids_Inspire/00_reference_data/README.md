# Reference Data (Published Sources)

This folder contains curated datasets directly extracted from published
literature and public catalogues. These files are not original data products
of the present work, but are used as reference inputs for cross-matching,
comparative tests, and contextual analysis.

## Files

- inspire_structure_age.csv  
  Structural age estimates for INSPIRE relic galaxies, as reported in the
  INSPIRE collaboration publications.

- inspire_lenses_data.csv  
  Lensing-related properties compiled from published INSPIRE datasets and
  associated studies.

## Notes

- No raw observational data are stored in this repository.
- All reference datasets remain subject to the original publications and
  should be cited accordingly.
- These files are provided here solely for reproducibility and transparency
  of the analysis pipeline.
