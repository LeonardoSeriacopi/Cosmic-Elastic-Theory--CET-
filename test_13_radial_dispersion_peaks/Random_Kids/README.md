# \### Random\_Kids/

# 

# 00\_data  

# Initial reference datasets derived from KiDS DR4, including random anchor selections

# and consolidated peak measurements used throughout the analysis.

# 

# 01\_catalog\_assembly  

# Construction of the working catalogues: merging centres, peak locations,

# and auxiliary quantities required for downstream tests.

# 

# 02\_modal\_scale  

# Identification and robustness tests of the modal dispersion-peak scale,

# including bootstrap and KDE-based analyses.

# 

# 03\_environment  

# Environmental and cluster-removal tests assessing the sensitivity of

# the dispersion peak to large-scale structure contamination.

# 

# 04\_statistical\_tests  

# Global statistical diagnostics, including redshift dependence,

# correlation tests, and distribution-level comparisons.

# 

# 05\_envelope\_analysis  

# Non-parametric envelope analysis of the dispersion-peak scale

# as a function of mass proxies or redshift, used as a consistency check.
