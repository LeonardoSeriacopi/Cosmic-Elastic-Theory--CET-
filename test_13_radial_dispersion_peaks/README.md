# \# Radial Dispersion Peaks in Weak Lensing

# 

# This repository contains the analysis pipeline, scripts, and derived data products

# used in the study \*\*“Radial Dispersion Peaks as Geometric Observables in Weak Lensing”\*\*.

# 

# The analyses are organized by \*analysis stage\* rather than by file type.

# Each directory contains the scripts, figures, and intermediate products

# required for that specific step.

# 

# The repository is divided into two main branches:

# \- \*\*Random\_Kids\*\*: reference analyses using random KiDS anchors

# \- \*\*Kids\_Inspire\*\*: analyses involving INSPIRE relic galaxies

# 

# Raw survey data are not included. All omitted data products can be reconstructed

# from public KiDS and INSPIRE catalogues using the scripts provided here.
